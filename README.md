# Portfolio – Hakim Rizki Pratama

Static site, no build step. Works on GitHub Pages as-is.

## Deploy to GitHub Pages
1. Create a public repo named exactly `exmachina30.github.io`.
2. Upload everything in this folder (index.html, assets/, Resume_HakimRizkiPratama.pdf) to the repo root.
3. Go to Settings → Pages, set Source to "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute the site is live at https://exmachina30.github.io

## Updating
- New resume: replace Resume_HakimRizkiPratama.pdf (keep the same file name).
- New case study: copy one `<article class="case">` block in index.html, change the text, and add its diagram to assets/.
